# Sparse mean

Computers the mean of a full vector represetned by a sparse object

## Usage

``` r
mean(x)

# S4 method for class 'sparse_numeric'
mean(x)
```

## Arguments

- x:

  A 'sparse_numeric' object

## Value

A 'sparse_numeric' object

## Functions

- `mean(sparse_numeric)`: Mean of a sparse vector
